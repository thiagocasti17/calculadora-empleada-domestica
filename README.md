# calculadora-empleada-domestica
Calculadora del costo de una empleada doméstica en Argentina: sueldo según categoría y horas, antigüedad, cuota de ARCA y aguinaldo, por mes y por año. Escala de octubre de 2026 (Res. CNTCP 6/2026). Gratis, sin registro, HTML, CSS y JavaScript puro. Resultados orientativos, no reemplaza a un contador.
